# PagePilot

PagePilot is an AI-powered tool for generating SEO-friendly blog posts and landing pages automatically.

## Features
- Generate blog articles optimized for search intent
- Suggest keywords and topic angles
- Draft structured, readable content for SEO campaigns
- Help create content that is fast to publish and easy to iterate

## Why PagePilot?
PagePilot helps content teams and creators turn ideas into high-quality, search-ready pages with less manual work.

## Getting Started
```bash
npm install
npm run dev
```

## Tech Stack
- Node.js
- React / Next.js
- AI content generation APIs
- SEO analysis tooling
